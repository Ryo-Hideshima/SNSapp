# 機能定義書: ユーザー登録機能

## 機能概要
メールアドレスとパスワードによる新規ユーザー登録を行う。登録時に基本プロフィール（表示名・自己紹介・アイコン画像）を設定できる。また本機能はフォロー／フォロワー機能（ユーザー間のフォロー関係の管理）を含む。

## 事前条件／利用者権限
- 新規登録: 未ログイン状態でも利用可能
- プロフィール編集: ログイン済みかつ本人のみ
- フォロー／フォロー解除: ログイン必須。自分自身はフォロー不可

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| メールアドレス | 必須 | メール形式であること、登録済みメールアドレスとの重複不可 |
| パスワード | 必須 | 最低8文字以上、英数字混在を推奨 |
| ユーザー名（username） | 必須 | 半角英数字・アンダースコア、他ユーザーと重複不可（`@username`として利用） |
| 表示名（display_name） | 任意 | 未入力時はusernameを表示名として使用 |
| 自己紹介（bio） | 任意 | 最大160文字程度 |
| アイコン画像（avatar_url） | 任意 | 未設定時はデフォルトアイコンを表示 |

## 処理フロー（正常系）
1. 新規登録画面でメールアドレス・パスワード・ユーザー名を入力し送信
2. サーバー側でバリデーション・重複チェックを実施
3. パスワードをハッシュ化して `users` テーブルに登録
4. 登録完了後、任意でプロフィール項目（表示名・自己紹介・アイコン）を設定
5. ログイン状態としてタイムライン画面へ遷移

### フォロー処理
1. プロフィール画面またはユーザー検索結果画面で対象ユーザーの「フォロー」ボタンを押下
2. `follows` テーブルに `follower_id`（自分）と `followee_id`（対象）のレコードを作成
3. フォロー解除は該当レコードを削除

## 異常系・エラーケース
- メールアドレス重複 → 登録エラーを表示し再入力を促す
- ユーザー名重複 → 別のユーザー名を促す
- パスワード強度不足 → エラーメッセージを表示
- 自分自身へのフォロー操作 → 操作を無効化（ボタン非表示 or エラー）
- 既にフォロー済みのユーザーへの再フォロー → 冪等に扱う（エラーにしない）
