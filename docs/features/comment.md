# 機能定義書: コメント機能

## 機能概要
ログインユーザーが投稿にコメントできる。投稿者本人だけでなく、第三者のユーザーもコメント可能。投稿ごとのコメント数を表示する。

## 事前条件／利用者権限
- コメント投稿: ログイン必須（投稿者以外の第三者も可）
- コメント削除: ログイン済みかつコメント投稿者本人のみ

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| コメント本文 | 必須 | 最大140文字程度 |

## 処理フロー（正常系）
1. 投稿詳細画面のコメント投稿フォームにコメント本文を入力し送信
2. `comments` テーブルに `post_id`・`user_id`・`content` を保存
3. コメント一覧に新しいコメントが反映され、対象投稿のコメント数（`comments`件数の集計）が更新される
4. コメント投稿者名クリックでコメント投稿者のプロフィール画面へ遷移

## 異常系・エラーケース
- コメント本文が空 → 投稿不可としてエラー表示
- 対象投稿が削除済み → コメント投稿不可、エラーメッセージ表示
- 他人のコメントを削除しようとした場合 → 403エラーとしてアクセス拒否

## 関連画面
- 投稿詳細画面
- タイムライン画面（コメント数の表示のみ）

## 関連テーブル
- `comments`
