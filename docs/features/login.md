# 機能定義書: ログイン機能

## 機能概要
登録済みユーザーがメールアドレスとパスワードでログイン／ログアウトを行う。

## 事前条件／利用者権限
- ログイン: 未ログイン状態のユーザーが利用
- ログアウト: ログイン済みユーザーが利用

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| メールアドレス | 必須 | メール形式であること |
| パスワード | 必須 | 未入力不可 |

## 処理フロー（正常系）
1. ログイン画面でメールアドレス・パスワードを入力し送信
2. サーバー側で認証情報を照合（Spring Securityを利用）
3. 認証成功時、認証トークン（JWT想定）を発行しクライアントに返却
4. タイムライン画面へ遷移
5. ログアウト操作時、クライアント側の認証情報を破棄しログイン画面へ遷移

## 異常系・エラーケース
- メールアドレスが未登録 → 「メールアドレスまたはパスワードが正しくありません」と表示（アカウント存在有無を特定させない）
- パスワード不一致 → 同上のメッセージを表示
- 認証トークン期限切れ → 再ログインを促す

## 関連画面
- ログイン画面
- 新規登録画面（未登録ユーザーへの導線）
