# 機能定義書: いいね機能

## 機能概要
ログインユーザーが投稿に「いいね」できる。投稿者本人だけでなく、第三者のユーザーもいいね可能。1ユーザーにつき1投稿に対して1回まで。投稿ごとのいいね数を表示する。

## 事前条件／利用者権限
- いいね／いいね解除: ログイン必須（投稿者以外の第三者も可）

## 入力項目・バリデーションルール
- 入力項目なし（いいねボタンの押下のみ）
- `likes` テーブルは `(post_id, user_id)` の組み合わせでUNIQUE制約を設け、同一ユーザーの重複いいねを防止する

## 処理フロー（正常系）
1. タイムライン／投稿詳細画面の「いいね」ボタンを押下
2. `likes` テーブルに `post_id`・`user_id` のレコードを作成
3. 対象投稿のいいね数（`likes`件数の集計）が更新され、画面に反映
4. 再度ボタンを押下（いいね解除）した場合、該当レコードを削除

## 異常系・エラーケース
- 既にいいね済みの投稿への再いいね → UNIQUE制約違反を防ぐためAPI側で冪等に処理（トグル動作）
- 対象投稿が削除済み → いいね操作不可、エラーメッセージ表示
