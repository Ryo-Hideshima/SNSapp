# 機能定義書: 投稿機能

## 機能概要
ログインユーザーがテキストを投稿できる。画像（複数枚可）を添付でき、画像はAWS S3に保存する。自身の投稿は削除できる。

## 事前条件／利用者権限
- 投稿作成: ログイン必須
- 投稿削除: ログイン済みかつ投稿者本人のみ

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| 本文（content） | 任意（画像のみ投稿も可とするか要検討。本アプリでは本文必須とする） | 最大280文字程度 |
| 画像 | 任意 | 複数枚添付可、1枚あたりのファイルサイズ・形式（jpg/png等）を制限 |

## 処理フロー（正常系）
1. 投稿作成画面でテキストを入力し、任意で画像を選択
2. 画像がある場合、クライアントまたはサーバー経由でAWS S3にアップロードし、オブジェクトURL（`s3_key`）を取得
3. `posts` テーブルに投稿レコードを作成し、画像がある場合は `post_images` テーブルに紐づくレコードを作成（`sort_order`で表示順を保持）
4. 投稿完了後、タイムライン画面に新しい投稿が反映される
5. 投稿者名クリックで投稿者のプロフィール画面へ遷移

### 削除処理
1. 投稿詳細画面またはタイムライン上の投稿から「削除」を選択（投稿者本人にのみ表示）
2. `posts` レコードを削除（関連する `post_images`・`comments`・`likes` も削除、S3上の画像も削除）

## 異常系・エラーケース
- 本文が空かつ画像もなし → 投稿不可としてエラー表示
- 画像アップロード失敗（S3エラー等） → エラーメッセージを表示し再試行を促す
- 許可されていないファイル形式・サイズ超過 → アップロード前にクライアント側でエラー表示
- 他人の投稿を削除しようとした場合 → 403エラーとしてアクセス拒否
