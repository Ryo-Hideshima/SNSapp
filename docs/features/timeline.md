# 機能定義書: タイムライン機能

## 機能概要
ログインユーザーがフォロー中のユーザーの投稿を新着順に一覧表示する。

## 事前条件／利用者権限
- ログイン必須
- 表示対象は自分がフォローしているユーザーの投稿のみ（自分自身の投稿を含めるかは要検討、本アプリでは含める）

## 入力項目・バリデーションルール
- 入力項目なし（ページング用のカーソル／ページ番号のみ）

## 処理フロー（正常系）
1. タイムライン画面を開くと、ログインユーザーがフォローしているユーザーIDの一覧を取得
2. 対象ユーザーIDに紐づく投稿を `created_at` 降順で取得（ページング/無限スクロール）
3. 各投稿にいいね数・コメント数・画像を付与して一覧表示
4. 投稿者名クリックで投稿者のプロフィール画面へ遷移
5. スクロールに応じて追加の投稿を取得（無限スクロール）

## 異常系・エラーケース
- フォロー中ユーザーが0件 → 「フォロー中のユーザーがいません」等の空状態を表示
- 投稿取得APIエラー → エラーメッセージを表示し再読み込みを促す

## 関連画面
- タイムライン画面

## 関連テーブル
- `posts`
- `post_images`
- `follows`
- `likes`（いいね数集計）
- `comments`（コメント数集計）
