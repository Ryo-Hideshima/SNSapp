# 要件定義書

## 概要
X/Twitterのタイムライン形式を模した学習用SNSアプリ。テキストベースの投稿を中心に、コメント・いいね・フォローといったソーシャル機能を備える。

## 対象範囲

- 利用者: 受講生・個人が想定利用者だが、複数ユーザーが同時に利用することを前提に設計する
- 対象機能: 下記「機能一覧」を参照
- 対象外機能: X（旧Twitter）との差別化・学習目的でのシンプル化のため、インプレッション数の表示およびリツイート（リポスト）機能は実装しない。詳細は[features.md](features.md#対象外機能本アプリでは実装しない機能)を参照

## 機能一覧

詳細は [features.md](features.md) を参照。各機能の詳細な仕様は `features/` 配下の機能定義書を参照。

| No | 機能名 | 概要 |
|----|--------|------|
| 1 | ユーザー登録機能 | メール／パスワードでの新規登録、基本プロフィール設定、フォロー／フォロワー機能 |
| 2 | ログイン機能 | ログイン／ログアウト |
| 3 | タイムライン機能 | フォロー中ユーザーの投稿を新着順に表示 |
| 4 | 投稿機能 | テキスト投稿（画像添付可）、投稿削除 |
| 5 | コメント機能 | 投稿へのコメント（第三者も可）、コメント数表示 |
| 6 | いいね機能 | 投稿へのいいね（第三者も可）、いいね数表示 |
| 7 | ユーザー検索機能 | ユーザー名・表示名でのユーザー検索 |

## 用語定義

| 用語 | 説明 |
|------|------|
| タイムライン | ログインユーザーがフォローしているユーザーの投稿一覧 |
| フォロー | あるユーザーが別のユーザーの投稿をタイムラインに表示させるための関係 |
| フォロワー | 自分をフォローしているユーザー |
| いいね | 投稿に対する好意的な反応。1ユーザー1投稿につき1回まで |

## 非機能要件（簡易メモ）

- 認証: Spring Securityによる認証を想定（JWTまたはセッションベース、詳細は実装時に決定）
- 画像ストレージ: 投稿画像・アイコン画像はAWS S3に保存し、DBには参照URL/キーのみ保持する
- 学習目的のプロジェクトのため、可用性・スケーラビリティ等は最小限の考慮とする（詳細は[infra-diagram.md](infra-diagram.md)のTODO参照）
